## The hard truth

- **The cel pass boils.** On pixels that do not move in the source, the cel frames change 4.8–9.4× as much (median 6.7×). The cel filter runs frame by frame, so the flats re-segment on every frame. That is unmotivated volume pulsing, which the prompt calls fatal.
- **Motion structure is only partly kept.** The correlation between source and cel frame-change curves is 0.13–0.77 (median 0.35). Where it is low, the flicker drowns out the real action.
- **Volume is not conserved between keys.** The median depth-scaled area drift per sequence is 10–59%, against a ±5% tolerance. Plane 2 masks come from per-key segmentation, so the 'character' changes identity as well as shape.
- **The fix order** is therefore not cosmetic: (1) stabilise the cel temporally by propagating flats along optical flow and re-segmenting only on keys, (2) track one P2 identity through each shot instead of re-segmenting per key, then (3) re-run the gates. Re-timing in the studio is safe meanwhile, because it moves exposures without repainting.
